① 경로 탐색에 필요한 데이터

휴대전화 GPS만으로 주변 보행자 수를 직접 측정할 수 없습니다. 사용 가능한 외부 데이터와 갱신 주기를 검증해야 합니다.

③ GPS · 안전 정보의 품질

위치 오차, 배터리 소모, 사고·공사·통제 알림의 지연과 오탐 문제를 별도 테스트합니다.

아래 일정은 기획서의 1~3개월 차 구현 계획을 그대로 개발 관점에서 재구성한 것입니다. 특정 시작일이나 실제 완료 날짜를 가정하지 않았습니다.

3개월 MVP 개발 로드맵

후속 확장 · 현재 개발 범위 제외

캐릭터·꾸미기 상점RUN 코인·퀘스트·뽑기유료 특수 재화스마트워치 페이스 코칭전국 확대광고·구독 사업화
개발 중 확인해야 할 사항을 해결된 사실이 아닌 검증 과제로 표시합니다. 외부 API나 데이터 제공 여부는 실제 조사 후 확정해야 합니다.

01 · 지도와 보행 네트워크

시범 지역 보행로 및 횡단보도 정보 확보, 경로 후보 생성 가능 여부, 지도 데이터 이용약관 확인.

02 · 신호등 수 추정

경로별 교차 지점과 신호등 연결 방식 설계, 지도상 정보와 현장 실측 차이 검증.

03 · 혼잡도 출처

보행자 밀집도를 대변할 데이터의 공간 해상도·시간 주기·라이선스 검토. 추정치는 명확히 표시.

04 · 위치와 페이스

모바일 GPS 권한, 거리 누적, 일시정지, 앱 백그라운드 동작, 배터리와 정확도 점검.

05 · 안전 알림

사고·공사·통제 정보 제공처와 업데이트 지연 여부 확인. 안전을 보장한다는 표현은 피하기.

06 · 사용자 검증

와이어프레임 흐름 이해도, 추천 지표 유용성, 만족도, 개선 요청 수집. 기획서의 제안 목표는 50명 이상.
